# Skill: intake-from-cos

Use when a stakeholder asks the **project chief of staff** for work that belongs in the factory.

## Job

Turn the chat ask into a **GitHub issue**. Do not build in chat.

## Steps

1. Confirm the target repo (and labels if used).
2. Create or refine one issue: title (outcome), body (context, constraints, done-when), links.
3. Reply in chat with the issue URL.
4. Stop. Pickup is `factory-loop` on that issue (you, another agent, or a watcher).

## Rules

- Chat clarifies; the issue is the handoff.
- Don't duplicate an existing issue — comment or refine it.
- Fuzzy scope: still file the issue; mark what needs a human before build.
